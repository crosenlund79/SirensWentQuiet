SIRENS WENT QUIET - Windows playtest build
==========================================

Run SirensWentQuiet.exe. No installation is needed.

- Controls: press H or F1 in game; F10 opens the developer (cheat) menu.
- Saves: %APPDATA%\Godot\app_userdata\Sirens Went Quiet\
- Your own art and sound: put files in the "custom" folder next to the
  .exe, mirroring the template names (custom\graphics\..., custom\audio\...),
  then restart the game. See assets/README.md in the repository.

This is an unsigned development build. Windows SmartScreen may warn on the
first start: choose "More info" and then "Run anyway".
